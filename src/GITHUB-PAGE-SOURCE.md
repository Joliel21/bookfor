# RARE Revolution Magazine page source

The reader loads the magazine page images directly from:

`https://raw.githubusercontent.com/Joliel21/Rare_Revolution_Magazine/main/`

Expected files:

- `cover.png`
- `inside-cover.png`
- `page-03.png` through `page-86.png`
- `inside-back-cover.png`
- `back-cover.png`

Updating those files on the repository updates the reader without rebuilding the theme, subject to normal browser/CDN caching.
